# S&P 500 모멘텀 × SEPA 스크리너

가중 모멘텀으로 S&P 500 전 종목을 매일 줄 세우고, **상위 20개에 마크 미너비니의 SEPA 점검을 적용**해 "모멘텀은 강한데 매수해도 되는 종목인가"를 판별합니다.

두 전략을 겹쳐 놓은 것이 핵심입니다.

| | 하는 일 | 출처 |
|---|---|---|
| **가중 모멘텀** | S&P 500을 수익률 가중합으로 랭킹 → 상위 20 추림 | `snp momentum` 전략 |
| **SEPA 점검** | 그 20개가 미너비니 기준에 맞는지 125점 만점 채점 | `stock-screener-main` 전략 |

모멘텀 1위가 곧 매수 대상은 아닙니다. 실제로 대부분의 모멘텀 상위 종목은 SEPA에서 걸러집니다 — 그 **탈락 이유를 보는 것**이 이 페이지의 목적입니다.

---

## 화면 구성

**요약 바** — SPY 국면 / 매수 적격 수 / 템플릿 통과 수 / Phase 2 수 / 평균 SEPA

**랭킹 행** (한 줄에 종목 하나, 눌러서 펼침)

```
#  종목    섹터   모멘텀   국면        템플릿      SEPA 점수        현재가
2  DELL    IT     11.12   P2 상승추세  ■■■■■■■■ 8/8  ███████░░ 100   $437.65
7  ZBRA    IT      8.05   P2 상승추세  ░░■■■■■■ 6/8  ███████░░  92   $364.24
```

- **템플릿 점 8개** — 미너비니 트렌드 템플릿 8개 조건. 채워진 칸이 통과. 20종목을 한눈에 비교하는 장치입니다.
- **SEPA 막대** — 125점 만점. 막대 위 세로선이 매수 임계선(60점)입니다.
- **초록 테두리 행** = 매수 적격.

**펼친 상세**

- 매매 계획 4단: 현재가 · 손절가 · 1차 익절 · 최종 익절
- SEPA 점수 구성 7개 항목 막대
- 트렌드 템플릿 8개 조건 체크리스트 (어느 조건에서 걸렸는지)
- 채점 근거 전문
- 매수 적격 / 보류 사유

## 점수 체계

### 가중 모멘텀 (랭킹 기준)

```
score = 12×(1개월 수익률) + 4×(3개월) + 2×(6개월) + 1×(12개월)
```

최근 1개월에 가중치를 몰아 단기 주도주를 빠르게 포착합니다. 가중치는 `config.MOMENTUM_WEIGHTS`에서 조정합니다.

### SEPA 점수 (125점 만점)

| 항목 | 배점 | 내용 |
|---|---|---|
| 추세 구조 | 40 | 이동평균 이격도 · 기울기 · 돌파 · 과열 페널티 |
| 펀더멘털 | 40 | 매출 3분기 QoQ 15 · EPS YoY 15 · 재고 10 |
| 손익비 | 15 | 2:1 미만 0점, 5:1 이상 만점 |
| 상대강도 | 10 | SPY 대비 20일 RS 기울기 |
| 거래량 | 10 | 상승일 거래량 / 하락일 거래량 |
| 진입 품질 | 5 | 52주 고가 근접도 (피벗 포인트) |
| VCP | 5 | 변동성 수축 패턴 품질 보너스 |

### 미너비니 트렌드 템플릿 8개 조건

1. 주가 > 150일선 · 200일선
2. 150일선 > 200일선
3. 200일선 1개월 이상 상승
4. 50일선 > 150일선
5. 주가 > 50일선
6. 52주 저가 대비 +30% 이상
7. 52주 고가 대비 −25% 이내
8. Phase 2 (확정 상승추세)

### 매수 적격 판정

세 조건을 **모두** 만족해야 합니다.

```
Phase 2  AND  템플릿 7/8 이상  AND  SEPA 60점 이상
```

> **원본과의 차이** — `stock-screener-main`의 `score_buy_signal()`은 Phase 2가 아니거나 템플릿 미달이면 즉시 0점을 반환합니다. 이 프로젝트는 그 조기 반환을 걷어낸 진단용 채점기(`src/sepa.py`)를 씁니다. 배점 체계는 원본과 동일하되, 모멘텀 상위 종목이 **어떤 국면에 있든 점수 내역을 항상 볼 수 있게** 하고 적격 여부만 따로 표시합니다. 그래서 "SEPA 92점인데 매수 보류"(ZBRA, 템플릿 6/8) 같은 상태가 표에 드러납니다.

## 실행

```bash
pip install -r requirements.txt
```

```bash
python run_daily.py
```

| 옵션 | 설명 |
|---|---|
| `--top N` | SEPA 분석 대상 상위 종목 수 (기본 20) |
| `--no-fundamentals` | 펀더멘털 조회 생략 — 빠른 테스트용 |
| `--output PATH` | HTML 출력 경로 (기본 `docs/index.html`) |

전 종목 다운로드 약 20초 + 펀더멘털 20종목 약 30초 = **1분 내외**로 끝납니다.

## 자동 갱신

`.github/workflows/daily_scan.yml`이 **평일 12:00 UTC (밤 9시 KST)** 에 실행됩니다. 미국장 마감 후라 당일 종가가 반영됩니다.

워크플로가 하는 일:
1. 스캔 실행 → `docs/index.html` + `data/daily/latest.json` 생성
2. 변경이 있으면 커밋 & 푸시 → GitHub Pages 자동 재배포
3. 결과를 아티팩트로 90일 보관

수동 실행은 GitHub Actions 탭 → **Daily Momentum x SEPA Scan** → Run workflow (상위 종목 수 지정 가능).

```
    ├── universe.py                 # S&P 500 목록 + 주가 배치 다운로드
    ├── momentum.py                 # 가중 모멘텀 점수
    ├── phase_indicators.py         # Phase 분류 · 트렌드 템플릿 · VCP (stock-screener-main에서 이식)

    ├── fundamentals.py             # yfinance 분기 재무
    └── report.py                   # HTML 리포트 생성
```
